# Unknown error → 새 채팅 직접 복구 (Autopilot 0.8.7)

## 발동 조건

등록된 ChatGPT 채팅에 **Unknown error**가 표시되고, 같은 오류 영역에 **새 대화 시작(Start new chat)** 버튼이 함께 확인될 때만 발동합니다. 답변·인용문·입력창에 적힌 오류 문자열은 무시합니다.

이 경우 원본 채팅이 더 이상 답변을 생성하지 못한다고 가정하므로, **`@이관`, 상태 요약 요청, 재전송을 원본 채팅에 보내지 않습니다.** 기존 길이제한 이관은 별도 경로로 유지합니다.

## 새 채팅 재구성

원본 채팅의 URL·등록 상태·프로젝트 ID·선택된 GitHub 저장소를 검증합니다. 자동 이관을 일시 정지한 뒤 다음 절차를 수행합니다.

1. 이전 채팅의 마지막 완료 답변을 *엄격하게 검증할 수 있을 경우에만* 한 건 확보합니다. 불가능하더라도 이관은 계속하며, 확인되지 않은 대화 내용을 만들어내지 않습니다.
2. 같은 ChatGPT **프로젝트 채팅**에서 발생했다면 해당 프로젝트의 새 채팅 화면으로, 일반 채팅이라면 일반 새 채팅 화면으로 이동합니다.
3. 새 채팅에 **마지막으로 확인된 작업 근거만 제공**하고, 접근 가능한 프로젝트 파일·프로젝트 지식·GitHub·관련 자료에서 최신 완료 현황·미완료 작업·블로커·승인사항·다음 작업을 독립적으로 확인하도록 요청합니다.
4. 새 채팅에 정확한 사용자 인계 메시지가 등록됐는지, 새 답변이 완료됐는지 검증합니다. 이후 같은 Chrome 탭의 등록 연결을 새 URL로 바꾸고 자동 진행 설정을 복구합니다.

검증 가능한 마지막 답변이 없다면 **기존 전체 대화를 복구했다고 표시하지 않습니다.** 새 채팅이 자료에 접근할 수 없는 경우에도 완료 사실을 추측해서는 안 됩니다.

## 안전 규칙

- 전체 자동화 정지, 미등록 채팅, 정확히 일치하지 않는 URL·탭, 오류 배너 불일치 → 작동하지 않음
- 원본 채팅에 프롬프트 전송 없음. 새 채팅 생성·인계 전송 결과가 불명확하면 **재시도하지 않음**
- Chrome 서비스 워커 재시작으로 이관 상태가 불완전하면 해당 채팅을 개입 필요 상태로 격리
- ChatGPT 프로젝트 밖에서 만들어진 새 채팅은 기존 프로젝트 채팅의 후계로 등록하지 않음
- 실제 GitHub CI 판정·Telegram·사용자 승인에 대한 권한을 자동으로 확대하지 않음
- 기존 등록 채팅만 감시하며, 등록하지 않은 탭 전체를 무단 조작하지 않음

## 검증 현황

- Sun PC 개발 분기 자동 회귀 **493/493 통과**
- 일반/프로젝트 채팅, 이전 답변 없음, 프로젝트 경계, 오류 UI 위조, 전체 정지, 불확실한 전송 처리 테스트
- 실제 ChatGPT의 `Unknown error` 화면을 발생시켜 새 채팅 인계까지 완료하는 관통 시험은 아직 수행하지 않았음

구현: `extension/unknown-error-page.js`, `extension/generic-migration.js`, `extension/generic-migration-page.js`.
