## 2026-11-08 — Unknown error 직접 복구 및 워크로그 중심 이관 개선

- **목표:** 대화 길이 제한 없이 `Unknown error` + `새 대화 시작`이 표시되는 경우 기존 대화에 이관용 요청을 보내지 않고, 같은 ChatGPT 프로젝트에서 복구.
- **원인:** `extension/unknown-error-page.js`의 실제 한글 버튼 패턴이 깨져 있어 오류 화면 감지 실패. 새 채팅 홈으로 이동한 뒤 사용자가/서비스가 다른 대화 URL로 전환하면 기존 `target_home` 단계가 영구 대기 가능.
- **수정 파일:** `extension/unknown-error-page.js`, `extension/generic-migration.js`, `extension/manifest.json`, `tests/chat-unknown-error-migration.test.js`, `tests/chat-generic-migration.test.js`, `tests/chat-runtime-diagnostics.test.js`.
- **복구 절차:** 정확히 확인된 오류 배너 및 새 채팅 버튼이 있을 때만 예외 복구 실행. 원본에는 메시지를 다시 보내지 않음. 저장된 프로젝트와 저장소를 기반으로 새 채팅 복구. 마지막 응답이 있으면 제한된 참고 자료로 취급하며, 없으면 최신 WORKLOG와 ROADMAP·코드·PR·CI부터 직접 확인하도록 새 채팅에 지시.
- **중복 방지:** 목표 URL이 이미 실제 새 채팅으로 바뀌면 최초 이관 nonce와 원본 프로젝트의 전송 확인 증거가 있을 때만 재연결·후속 완료 단계로 이동. 증거가 없으면 `GENERIC_TARGET_CHANGED_NO_TRANSFER_PROOF`로 정지하며 재전송·재생성 금지. 목표 홈 로딩/이동이 2분 이상 지속되는 경우 명시적인 차단 사유 기록.
- **현장 관찰:** 기존 정지 기록 2건이 `target_home` 단계에서 약 336분·24분 체류했고, 실제 브라우저 탭은 이미 같은 프로젝트의 서로 다른 채팅 URL로 바뀐 상태였음. 두 대상 모두 원본 이관문 증거가 확인되지 않아 자동으로 덮어쓰지 않음.
- **검증:** 전체 `npm run check` **645개 통과**. 실제 한글 버튼·영문 버튼·잘못된 버튼, 기존 전송 확인/미확인 새 채팅 분기, 2분 정체를 별도 테스트.
- **버전:** Chrome 확장 프로그램 `0.4.66`.
- **미완료:** 기존 정지 2건은 실제 신뢰 가능한 이관 증거가 없어 재개 보장 불가. 해당 채팅의 새 경로에서 안전하게 다시 재구성할 필요가 있음.

## 2026-11-08 — 전체 자동 실행 중지 진단 및 화면 검증 실패 자동 복구

- **현황:** 전역 자동 실행은 켜져 있으나 8개 등록 중 2개만 enabled 상태로 시작. OBSERVATION_UNVERIFIED 3건(운영·결제·어드민), 승인 감지 1건(AI 보안), AUTO_MIGRATION_NEEDS_ATTENTION 1건(장기기억), 의도적 수동 중지 1건(관상 별도 등록).
