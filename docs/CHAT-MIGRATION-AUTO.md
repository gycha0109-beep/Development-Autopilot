# 자동 길이 제한 감시 → 무인 이관

Chrome 확장 버전 0.4.8, composer-2026-10-14-r9.

## 사용자 요구

등록한 개발 채팅을 주기적으로 감시하여 ChatGPT 최대 대화 길이 경고가 실제 페이지에 나타나면 추가 수동 버튼 없이 다음 절차를 자동 실행합니다.

1. 원본 탭에 길이 제한 경고가 노출된 것을 확인합니다. 인용된 채팅 메시지는 경고로 취급하지 않습니다.
2. localhost의 연결된 작업축 자동 후속 지시를 즉시 중지하고 해당 탭을 한 번만 처리하도록 기록합니다.
3. 원본 대화에서 저장소 로드맵을 참조하는 이관용 프롬프트 작성을 한 번 요청합니다.
4. 원본 대화에서 이관 요청이 전송되지 않거나 답변이 확인되지 않으면 중단합니다. 다른 답변이나 임의로 합성한 이관문을 대신 사용하지 않습니다.
5. 실제 동일 프로젝트 식별자를 가진 새 프로젝트 채팅 탭을 Chrome이 만들고 원본과 같은 탭 그룹에 넣습니다.
6. 원본 채팅이 실제 작성한 이관문을 새로운 프로젝트 채팅의 첫 메시지로 삽입·전송합니다. 최대 30,000자입니다.
7. 새 대화 생성 후 첫 assistant 응답이 종료되고 같은 출력이 6초간 유지되는지 확인합니다.
8. 기존 채팅 제목 끝 숫자를 1 증가시켜 새 대화 제목을 실제 ChatGPT UI에서 변경하려 시도합니다.
9. 같은 프로젝트의 새 채팅에 한해 원래 등록 세션 키의 Chrome 탭 주소를 재연결하고 localhost에 동기화합니다.
10. 이관 직전에 승인된 주기 자동 전송이 아직 유효하고 최대 횟수에 도달하지 않았으면 해당 작업축의 기존 설정 그대로 복구합니다.

## 최초 설정

- 기존 프로젝트 개발 채팅 탭을 Chrome 탭 그룹 및 Autopilot 확장에 등록합니다.
- 확장 옵션의 '길이 제한 자동 감지 → 자동 이관' 영역에서 등록 채팅, 현재 제목(예: 사주 범용화 및 권한 통합 3), GitHub 저장소를 입력합니다.
- '자동 감시 켜기'를 한 번 클릭해 명시적으로 승인합니다. 이후 감지·이관·제목 변경·재연결은 자동으로 진행됩니다.
- 서버 npm.cmd start 및 확장 연결을 유지해야 합니다. Chrome alarms와 로컬 동기화를 통해 약 1분 간격으로 감시합니다.

## 안전 제약과 남은 리스크

- 소스는 실제 기존 프로젝트 대화 URL이어야 하며, 다른 프로젝트로의 이관을 허용하지 않습니다.
- Chrome 등록 탭 및 로컬 페어링 없이 동작하지 않습니다. 전체 STOP 사용 시 모든 자동 이관도 정지합니다.
- 입력창 초안, 진행 중 응답, 중복 또는 불명 전송은 재시도 없이 확인 필요로 전환합니다.
- 제목 메뉴가 바뀌어 자동 이름 변경을 검증할 수 없으면 확인 필요 상태로 정지합니다. 제목 변경에 성공했다고 허위 표시하지 않습니다.
- Chrome 서비스 워커 재시작 중 불확실한 작업은 자동 재전송하지 않습니다.
- 영속화되는 설정에는 저장소·제목·원본 URL 트리거 지문만 기록하고 이관문 본문은 Chrome 세션 저장소에만 임시로 보관해 전송 직후 폐기합니다.
- 로그인 만료·메시지 길이 초과·Chrome DOM 변경·서비스 워커 중단과 같은 상황은 사용자 확인이 필요할 수 있습니다.
- 기존 자동 전송의 승인 기간과 최대 횟수를 절대 늘리지 않으며, 만료된 승인을 자동 재활성화하지 않습니다.
- 실제 Chrome 프로젝트 첫 응답·제목 메뉴·신규 채팅 URL은 Windows에서 추가 실기기 검증이 필요합니다.

## 적용

git fetch origin
git switch --track origin/feat/chat-migration-auto-watch

기존 npm.cmd start를 Ctrl+C로 중지한 뒤 npm.cmd start를 다시 실행합니다. 기존 Chrome 옵션 페이지를 닫고 chrome://extensions에서 확장을 새로고침한 뒤 새 옵션 페이지를 엽니다.
버전 0.4.8 / composer-2026-10-14-r9을 확인하고 자동 감시할 등록 프로젝트 탭을 선택하십시오.

## 작업축·등록 탭 삭제와 감시 목록 정리 (v0.4.15)

- Chrome 확장에서 등록 탭을 해제하거나 등록 그룹을 삭제하면 해당 sessionKey의 자동 이관 감시 설정, 진행 상태, 가상 경고 예약을 함께 정리합니다. 단순 네트워크 끊김·일시 정지는 삭제하지 않습니다.
- 로컬 Autopilot 작업축을 삭제할 때 **Chrome 브리지에 명시적으로 연결된** 세션이 있으면 해당 확장에 감시 해제 기록을 전달합니다. 브리지는 다음 동기화에서 제거를 확인할 때까지 해제 기록을 유지합니다.
- 과거 삭제되어 연결 기록이 남지 않은 항목은 자동으로 어느 작업축의 것이었는지 증명할 수 없습니다. 확장 옵션의 감시 항목 옆 **감시 항목 삭제** 버튼으로 명시적으로 제거합니다.
- 제거되더라도 동일 원본 URL의 이전 이관 요청 중복 전송 방지 기록은 유지합니다. 다른 등록 세션 또는 진행 중인 독립 작업축은 삭제하지 않습니다.
- 브리지가 오프라인이면 로컬 작업축 삭제의 감시 해제는 다음 성공적인 동기화 때 반영됩니다. Windows 실기기 확인은 별도입니다.
