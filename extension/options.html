등록 및 연결 복구

Chrome을 완전히 다시 시작했거나 탭이 다른 대화로 이동한 경우, 수동으로 연결을 확인합니다.

길이 제한 자동 감지 → 자동 이관

한 번 설정하면 확장이 등록된 개발 채팅을 약 1분마다 확인합니다. 길이 제한이 발견되면 로드맵 기반 이관문 요청(불가 시 자동 대체)부터 동일 프로젝트 새 대화 생성·전송, 첫 답변 대기, 제목 +1, 작업축 재연결과 이전 자동 주기 복구까지 순서대로 시도합니다.

ChatGPT 채팅 제목 · 자동 인식
채팅을 선택하면 실제 제목을 확인합니다.

테스트 버튼은 선택한 등록 프로젝트 채팅에서 경고 감지만 1회 가상으로 발생시킵니다. 이후에는 실제로 원본에 이관문을 요청하고 새 프로젝트 채팅을 생성·전송합니다. 연습용 ChatGPT 프로젝트/대화에서만 사용하십시오. 전체 정지 시 실행되지 않습니다.

감시를 활성화한 등록 채팅에서만 작동합니다. 경고가 뜨면 추가 버튼 없이 자동 이관합니다. 로컬 전체 정지 시 동작하지 않으며, 제목 변경 UI나 전송 결과가 불확실한 경우 자동 재전송 없이 확인 필요 상태로 전환됩니다.

개발 대화 이관 · 복사 → 새 프로젝트 채팅

원본 대화에서 로드맵 기반 이관 프롬프트를 요청하고, 답변만 새 프로젝트 채팅의 첫 메시지로 옮깁니다. 첫 응답 이후 제목 변경을 시도하며 실패하면 직접 변경하도록 안내합니다. 자동 API 과금 없음.

원본 채팅 제목 · 자동 인식
원본 대화를 선택하면 제목을 자동 확인합니다.

최대 길이 경고로 원본에서 새 메시지를 보낼 수 없다면 기존에 작성해 둔 이관 프롬프트를 아래 입력창에 직접 붙여넣을 수 있습니다. 오류가 나도 기존 명령을 재전송하지 않습니다. 이관문 최대 30,000자.
